# React Redux Cart Project

This is a simple React project where I practiced React, Redux Toolkit and React Router DOM.

## Features

- Fetch products from DummyJSON API
- Show product list
- Show product details
- Add products to cart
- Increase and decrease quantity
- Remove products from cart
- Clear cart
- Show cart count
- Show total price
- Dynamic routing using `useParams()`

## Technologies Used

- React
- Redux Toolkit
- React Redux
- React Router DOM
- JavaScript
- CSS
- DummyJSON API

## Main Pages

- `/products` - Shows all products
- `/products/:id` - Shows details of a specific product
- `/cart` - Shows all products added to the cart
